## **Health Tracker**

>Creating a Samsung Health-like application for Android, utilizing different phone sensors and permissions.
>Features include, but are not limited to:
 - Personal account and app personalization.
 - Uses and syncs a cloud database in Firebase Realtime Database, as well as a local database RoomDB, so as to be used when offline.
 - Measures your steps in real time, as well as keeps track of calories you burn through the day and graphs your progress.
 - Also supports async friends lists and sending challenges for different activies or checking your friends' activity.
 - Achievement system (small).
